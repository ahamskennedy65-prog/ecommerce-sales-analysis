# E-commerce Sales Analysis

## 📊 Project Overview

This project analyzes e-commerce sales data from January
to August 2026 to understand business performance,
revenue trends, product sales, and customer purchasing patterns.

The project uses Excel, PostgreSQL, Python, and Power BI
for data analysis and reporting.

## 🛠️ Tools and Technologies

- Excel — Data exploration and analysis
- PostgreSQL — SQL queries and business analysis
- Python (Pandas) — Data processing and analysis
- Power BI — Interactive dashboards and visualization

## 📁 Dataset

The dataset contains 1,000 e-commerce transactions
recorded between January and August 2026.

## 🔍 Analysis Objectives

1. Analyze overall sales performance.
2. Identify top-performing product categories.
3. Examine regional sales distribution.
4. Calculate business performance indicators.
5. Develop an interactive Power BI dashboard.
